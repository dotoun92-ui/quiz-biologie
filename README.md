# Quiz Biologie

Ce projet contient une application web de quiz de biologie avec 50 questions mélangées sur :
- physiologie
- biochimie
- microbiologie
- immunologie
- anatomie
- questions pratiques

## Structure

- `index.html` : page principale
- `style.css` : style de l’interface
- `script.js` : logique du quiz

## Lancer le projet

1. Ouvrez le dossier du projet.
2. Double-cliquez sur `index.html` dans votre navigateur.
3. Cliquez sur "Commencer" pour lancer le quiz.

## Fonctionnalités

- 50 questions aléatoires (dans l’ordre défini dans le code)
- Système de score
- Explications après chaque réponse
- Boutons de navigation : Retour et Suivant
- Affichage final du résultat

## Personnalisation

Vous pouvez modifier les questions dans le tableau `questions` dans le fichier `script.js`.

## Améliorations possibles

- Ajouter un timer par question
- Ajouter des catégories
- Gérer les niveaux de difficulté
- Sauvegarder le score dans le navigateur
- Ajouter une version plus moderne avec animation
